# 08. 実験の進め方

推薦システムの実験では、モデルを増やす前に比較条件を固定することが重要です。

見るファイル:

- `recsys_lab/run.py`

重要な考え方:

- 同じ dataset, split, metric で比較する
- baseline を必ず置く
- 指標だけでなく実際の推薦リストを見る
- ハイパーパラメータは一度に一つずつ変える

## Exercises

1. `make run` の結果を保存し、モデルごとの指標を比較してください。
2. `K=3`, `K=5`, `K=10` で評価結果を比べてください。
3. 指標が高いのに推薦リストが直感的に悪く見える例を探してください。
